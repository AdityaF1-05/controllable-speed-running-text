# CONTROLABLE SPEED RUNNING TEXT

![PlatformIO](https://img.shields.io/badge/PlatformIO-F6821F?style=for-the-badge&logo=platformio&logoColor=white)
![Arduino](https://img.shields.io/badge/Arduino-00979D?style=for-the-badge&logo=arduino&logoColor=white)

A Running Text, simple using Potensiometer for controlling the speed of running text. Using PlatformIO and C++, with Microcontroller Arduino Nano and OLED Module

## ⚙️ Technical Features

- Adjustable Speed : With ADC feature, the speed of running text is not static Anymore
- Rewrite the Text : Rewrite the text easily, just rewrite the main code

## 🛠️ Requirements

- Editor : Visual Studio Code (PlatformIO Installed Properly)
- Compiler : PlatformIO Compiler
- System Requirements :
  ```
  Minimum - SRAM 1 KB & Flash Memory 32 KB
          - Tools : Potensiometer & Analog In Pins

  Recommended - SRAM 2 KB
              - Tools : Same as minimum Requirements
  ```
